# Security Policy

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security
vulnerabilities. Instead, email the maintainer directly at:

    <security-contact-placeholder@example.com>

Replace the placeholder above with a real monitored address before
publishing this repository. Include:

- A description of the vulnerability and its impact
- Steps to reproduce
- Affected version (`setup-ai --version`)

## Scope

This policy covers FIREWING's own code (`firewing/`, `setup_ai/`,
deployment scripts). Vulnerabilities in the upstream Qwen3-Omni model
itself should be reported to the Qwen team via their own repository:
https://github.com/QwenLM/Qwen3-Omni

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x-beta | Yes, during beta |

This is a beta project — expect faster-than-usual security patch
cycles and occasional breaking changes as issues are found.
